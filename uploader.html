WarLab Uploader

WarLab Uploader is War Lab's own internal publishing tool. The War Lab developer uses it inside the War Lab Unity project (a desktop editor window) to publish War Lab gameplay videos to War Lab's own official accounts. It is not offered to the public and acts on no other user's account.

What it does

  • YouTube (YouTube API Services): uploads a video the developer selects to the official War Lab YouTube channel, with the title, description, tags and privacy setting the developer typed in, after the developer confirms "Post". It reads the channel's name only to show which channel is signed in.
  • Other War Lab accounts: TikTok, Instagram, the War Lab Facebook Page, Discord announcements and r/WarLab on Reddit.

YouTube

WarLab Uploader uses the YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google data is handled as described in our Privacy Policy and the Google Privacy Policy. Access can be revoked at any time from Google's security settings or with the tool's "Sign out of YouTube".
